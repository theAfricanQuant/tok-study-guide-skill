# Learning design for continuing courses

Use this reference when the learner is following a sequence of guides or explicitly wants progress carried into later sessions. A single-use study guide does not need these files.

## Course files

Keep course state beside the course materials, not in chat memory alone:

- `MISSION.md`: the learner's goal, practical context, current level (if known), constraints, and what success looks like.
- `RESOURCES.md`: source IDs, title/type/link, useful page/time/slide/file anchors, and a short note about what each source contributes. Record conflicts and inaccessible portions.
- `NOTES.md`: concise concept explanations, worked examples, and links back to their source anchors.
- `learning-record.md`: only demonstrated knowledge, skills practiced, misconceptions corrected, and questions still open. Date entries and link to the exercise or learner response that supports them.

Start with the available files. Update them only when the lesson provides new evidence. Do not treat silence, a guessed answer, or an unattempted exercise as proof of mastery. If no record exists, use a short diagnostic with feedback and adjust the starting point.

## Teaching loop

For each major concept, connect:

1. **Knowledge:** explain the idea and its source-grounded meaning.
2. **Skill:** give the learner a small task that uses it: calculate, run, inspect, compare, explain, or build.
3. **Judgment:** interpret the result, state assumptions and limits, and decide when the method fits.

Give each session a practical mission and a small number of observable outcomes. Use retrieval questions to make the learner recall or apply an idea before showing feedback. Choose question format and difficulty to match the current evidence; do not use multiple choice as the default. Feedback should explain the reasoning and point back to the relevant lesson/source anchor.

Close by recording what the learner actually demonstrated and choosing the next exercise from that evidence. Keep the records short and useful: they should make the next session more tailored, not become a transcript of the course.
